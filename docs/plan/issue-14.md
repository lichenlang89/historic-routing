# Issue #14：配置生命周期与多网关接收

基线：`8ae604e`。实现分支：`codex/issue-14-egp-lifecycle`。

## 方案与边界

- 保留 network 增删时的进程、邻接、已有路由及 Update 接收窗口行为。
- systemd 使用同树 frr-reload，显式指定 egpd、配置目录、临时目录及 socket。
- CLI 补齐 AS/timers 删除，默认值为 AS 0、Hello/Poll 30/120；有邻居时拒绝修改。
  reload 在全局参数变化时先删除所有旧邻居，等 Cease 完成，再应用参数及目标邻居。
- 接收公共有类网络上的内部/外部网关，保留来源标记；逐网关保存候选及遗漏计数。
  按稳定候选顺序选择，距离不跨 AS 比较；不增加中继或 RIB 导入能力。
- 更新手册、能力账本与交接记录。使用独占容器与网络，保留修复前失败和测试日志。

## 验收与风险

快速测试、修复前/后 reload 和混合网关对照、原始报文回归、双向转发、完整构建、
man/HTML 构建，以及可用发行版安装环境的 systemd reload。保留未验证的平台边界。
全局参数变更会有意重建邻接；FRR reload 不是事务，运行期失败后需重新应用原配置。
