# protocols/

每个历史路由协议一个目录，目录之间互不引用。

| 目录 | 协议 | 规范 | 状态 |
| --- | --- | --- | --- |
| `egp/` | Exterior Gateway Protocol | RFC 904（Historic） | 源码已迁入（S3），逐字节来自 `egp-verified-20261024` |
| `ggp/` | Gateway-Gateway Protocol | RFC 823（Historic） | 尚未创建 |
| `hello/` | HELLO Routing Protocol | RFC 891（Historic） | 尚未创建 |

加新协议的手册见 `docs/ADD_A_PROTOCOL.md`；资源占用登记见 `docs/FIDELITY.md`。
